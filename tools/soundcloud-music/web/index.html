Источник и плейлист

При первом импорте macOS запросит доступ к приложению «Музыка».

Как это работает

Список берётся из Likes твоего профиля или из указанного плейлиста. Выбранные песни скачиваются по одной с обложками, затем добавляются в медиатеку «Музыки» и выбранный плейлист.

Недоступные песни и превью пропускаются. Повторно импортированные этим инструментом треки не добавляются, даже если сменить плейлист. Обложки уже перенесённых песен можно добавить отдельной кнопкой.

Для появления песен на iPhone включи «Синхронизацию медиатеки» в «Музыке». Возможность синхронизации зависит от подписки и файла.

Закрытые треки

Для закрытого списка выбери экспортированный файл cookies.txt SoundCloud в формате Netscape. Инструмент сохранит локально только cookies SoundCloud. Исходный файл останется без изменений.
