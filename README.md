# SoundCloud → Музыка

**Любимые треки SoundCloud — в локальной медиатеке Mac.**

Локальный инструмент с браузерным интерфейсом: собирает Likes профиля и песни сохранённых плейлистов, позволяет выбрать треки и добавляет аудиофайлы в приложение **«Музыка»** на macOS.

```text
SoundCloud Likes / плейлист
            ↓
Поиск → выбор треков → аудио + метаданные + обложки
            ↓
Локальные файлы → «Музыка» на Mac → выбранный плейлист
```

## Возможности

- Загрузка коллекции по ссылке на профиль, Likes или отдельный плейлист.
- Поиск, фильтры, выбор треков и отображение длинных списков порциями.
- Название, исполнитель и обложка в файле и в приложении «Музыка».
- Повторная попытка импорта с уже скачанным файлом и защита от повторного добавления по локальному журналу.
- Режим «только скачать», остановка очереди и сохранение прогресса между запусками.
- Последовательная обработка, ограничение скорости скачивания и проверка тепловой нагрузки перед перекодированием.
- Публичные коллекции без входа; для доступных владельцу закрытых треков — необязательный локальный файл cookies.

## Что переносится

Инструмент **импортирует аудиофайлы в локальную медиатеку macOS Music**. Он не сопоставляет треки с каталогом Apple Music и не создаёт облачный плейлист через MusicKit.

Появление файлов на iPhone зависит от отдельно настроенной синхронизации медиатеки и условий вашего аккаунта. Успешный импорт на Mac не гарантирует загрузку в облако. Apple ID, пароль и API-ключ Apple Music инструменту не нужны.

## Запуск на Mac

Нужны **macOS**, приложение **«Музыка»**, **Python 3.10+** и **ffmpeg** в `PATH`. Если Homebrew уже установлен, ffmpeg можно установить командой `brew install ffmpeg`.

1. Скачайте репозиторий или клонируйте его.
2. Дважды нажмите **SoundCloud в Музыку.command**. Скрипт создаст `.venv` внутри папки инструмента и при первом запуске установит Python-зависимости. Понадобится интернет.
3. В открывшемся локальном интерфейсе вставьте ссылку на профиль или плейлист SoundCloud и нажмите **«Загрузить список»**.
4. Выберите песни, задайте плейлист и нажмите **«Скачать и добавить»**. Для сохранения только файлов выключите **«Импортировать после скачивания»**.
5. Если macOS запросит доступ к «Музыке», разрешите управление в **Системные настройки → Конфиденциальность и безопасность → Автоматизация**.

Закрыть сервер: `Control+C` в окне запуска. Если у скачанного `.command` нет права запуска:

```sh
chmod +x "SoundCloud в Музыку.command"
```

Для запуска вручную из корня репозитория:

```sh
cd tools/soundcloud-music
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

Для установки точного снимка зависимостей используйте `requirements.lock.txt` вместо `requirements.txt`. Этот файл сохраняет версии исходной рабочей среды; для запуска на новой версии macOS или Python может потребоваться обновление зависимостей.

## Файлы и приватность

Сервер слушает только `127.0.0.1`, выбирает свободный порт и защищает API токеном сеанса с проверкой Host/Origin. Не публикуйте его в интернете.

Коллекция, файлы, обложки, cookies и журнал сохраняются в `tools/soundcloud-music/data/`. Эта папка исключена из Git. При выборе cookies сохраняются только строки SoundCloud, с правами `0600`; исходный файл не изменяется. Сам файл cookies даёт доступ к аккаунту — храните его локально.

**Не удаляйте `data/downloads` после импорта**, если «Музыка» не копирует добавленные файлы в свою медиатеку: приложение может ссылаться на эти файлы. Сохраните также `manifest.json`, чтобы не потерять защиту от повторного импорта.

## Ограничения

- Только доступное полное аудио: DRM, превью, удалённые и недоступные песни пропускаются. Используйте инструмент для аудио, которое вам разрешено сохранять.
- MP3/M4A по возможности копируются без повторного сжатия; несовместимый формат преобразуется в MP3. Перекодирование не улучшает исходное качество.
- Метаданные зависят от SoundCloud; при отсутствии исполнителя используется имя загрузившего трек пользователя.
- Защита от повторов работает по журналу инструмента, а не по всей существующей медиатеке. Уже импортированный трек не добавляется повторно даже при выборе другого плейлиста.
- Перед перекодированием очередь ждёт тепловое состояние `nominal`; при недоступном датчике делает паузу 90 секунд. Между треками есть пауза 3 секунды.
- SoundCloud и `yt-dlp` могут менять поведение. Полный перенос каждого трека не гарантирован.

## Проверка без переноса музыки

Из папки `tools/soundcloud-music` после установки зависимостей:

```sh
.venv/bin/python -m unittest discover -v
.venv/bin/python server.py --no-browser
```

Тесты используют искусственные данные и подменяют скачивание, ffmpeg и управление «Музыкой». Они проверяют импорт, повторы, отмену, обложки, обработку cookies и защиту локального HTTP API. Команда `--no-browser` запускает только сервер; перенос начинается после действия пользователя.

При подготовке этой версии 12 октября 2026 года прошли **34 offline-теста** на Python 3.14 с чистой установкой зависимостей из `requirements.txt`; также проверен синтаксис Python, JavaScript и запускного zsh-скрипта. Реальный перенос музыки в ходе этой проверки не выполнялся.

## Структура

```text
SoundCloud в Музыку.command       запуск на Mac
tools/soundcloud-music/
  core.py                        коллекция, очередь, файлы и импорт
  artwork.py                     проверка и запись обложек
  server.py                      локальный HTTP API
  web/                           интерфейс без сборщика
  test_*.py                      проверки без реального переноса
  requirements*.txt              Python-зависимости
tools/laptop-load/thermal.py      датчик тепловой нагрузки macOS
```
